# Codeforces Zen Mode

A browser extension designed to reduce contest anxiety by blocking access to live standings and obfuscating raw problem solve counts with a calculated difficulty index.

## What It Does

* **Standings Guard:** Automatically blocks access to live standings so you can focus on beating the problems, not your friends.
* **Difficulty Indexing:** Hides raw problem solve counts from the dashboard and replaces them with a relative difficulty index so you still know which problems to tackle first.

## Installation

### Firefox
Install it directly with one click from the [Firefox Add-ons Store](https://addons.mozilla.org/firefox/addon/cf-zen-mode/).

### Chrome/Brave (Manual Setup)
Since this extension is open-source and free, Chrome users can install it via developer mode:
1. Download the latest source code zip from the [Releases tab](https://github.com/adeed-exe/Codeforces-Zen-Mode/releases/tag/v1.0).
2. Extract the ZIP file to a folder on your computer.
3. Open Google Chrome and go to `chrome://extensions/`.
4. Enable **Developer mode** using the toggle switch in the top-right corner.
5. Click **Load unpacked** in the top-left corner and select your extracted extension folder.
